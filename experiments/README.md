# Experiments and diagnostics

This directory contains simulation drivers, numerical audits, and exploratory
follow-ups. Run them from the repository root as modules, for example:

```bash
python -m experiments.wor_scaled_plots --plot-only
```

The complete catalog and publication-scale commands are in
[`docs/EXPERIMENTS.md`](../docs/EXPERIMENTS.md). The authoritative command for
redrawing the paper figures remains `python reproduce_paper_figures.py`.
